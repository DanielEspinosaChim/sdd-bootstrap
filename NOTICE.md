# Créditos y licencias de terceros

Este proyecto incluye material de los siguientes repositorios, con sus licencias. Los textos completos están en `plugin/skills/sdd-bootstrap/assets/arnes/licencias/` y, para las skills de Anthropic, en el `LICENSE.txt` de cada carpeta.

| Repositorio | Qué se incluye | Licencia |
| --- | --- | --- |
| [yurukusa/cc-safe-setup](https://github.com/yurukusa/cc-safe-setup) | 6 hooks de seguridad (2 modificados; los cambios están marcados en cada archivo) | MIT |
| [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code) | Subagentes, skills y reglas | MIT |
| [wshobson/agents](https://github.com/wshobson/agents) | Subagentes y skills de backend, LLMs, RAG, fine-tuning, MLOps y datos | MIT |
| [obra/superpowers](https://github.com/obra/superpowers) | Skills de método (TDD, planes, debugging, revisión) | MIT |
| [anthropics/skills](https://github.com/anthropics/skills) | `claude-api`, `frontend-design`, `webapp-testing`, `mcp-builder`, `skill-creator` | Apache-2.0 |
| [anthropics/claude-code-action](https://github.com/anthropics/claude-code-action) y [anthropics/claude-code-security-review](https://github.com/anthropics/claude-code-security-review) | Base de los workflows de GitHub | MIT |
| [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) | Principios adaptados en la plantilla de `CLAUDE.md` | MIT |
| [ChrisWiles/claude-code-showcase](https://github.com/ChrisWiles/claude-code-showcase) | Patrón de revisión de PR | MIT |

Ideas tomadas, sin copiar texto: [trailofbits/claude-code-config](https://github.com/trailofbits/claude-code-config) (permisos y guards) y [trailofbits/claude-code-devcontainer](https://github.com/trailofbits/claude-code-devcontainer) (recomendado para aislamiento).
